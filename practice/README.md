# Practice problems

A few past Cloudflight Coding Contest problems, pulled in for practice ahead of the 2026 contest.

| Folder | Contest | Problem | Core technique |
|--------|---------|---------|-----------------|
| [desk-placement](desk-placement/) | Oct 2024 (40th CCC) | Place desks in a room, no touching | Backtracking DFS with pruning |
| [island-routing](island-routing/) | Oct 2023 (38th CCC) | Trace a ship route around an island's shore | BFS flood-fill + A* + convex hull |
| [lawn-mowing](lawn-mowing/) | Apr 2024 (39th CCC) | Hamiltonian path over a grid with one obstacle | DFS + Warnsdorff's heuristic |

Each folder has the problem writeup (`README.md`) and a reference C++17 solution (`solution.cpp`).

[dpaguba/cloudflight-coding-contest](https://github.com/dpaguba/cloudflight-coding-contest) by Dmytro Pahuba.
They're independent write-ups/solutions of past public CCC problems, not official Cloudflight material.
Treat the solutions as a reference to study, not a template to submit verbatim -- try solving cold first.
